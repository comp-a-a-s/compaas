# Real World Mode Asset Attribution

This package contains COMPaaS v1 isometric office sprites and props with a CC0-compatible usage model.

- Style target: low-poly block-crafted office sprites inspired by Sims + voxel readability.
- License policy for this folder: permissive and project-safe for shipping, modification, and redistribution.
- Replacement-ready: `sprite-manifest.json` is the single source of truth for swapping in future art packs.

If external CC0 packs are added later, append exact source links and license metadata here.
